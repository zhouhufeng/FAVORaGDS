# FAVOR tar.gz to GDS: Execution Runbook

**Date:** Sept 2026

This runbook converts the public GRCh38/hg38 FAVOR Essential and FAVOR Full CSV tar.gz archives to one SeqArray GDS file per autosome. It is intended to be executed on a separate Linux/HPC machine. The converter is **`GDSAnnotator::seqToGDS_FAVOR_tar()`**; it reads CSV members directly from each `.tar.gz` file, so do not extract the archives.

The documented results cover chromosomes 1-22. The code supports `X`, `XY`, and `Y` if matching archives are obtained, but their file IDs and expected sizes are not included here.

## 1. Requirements and capacity

Use Linux with `bash`, GNU `tar`, `wget` (or `curl`), and a working R installation (R >= 4.0). The packages below compile native code, so a C/C++ toolchain plus development headers for zlib, bzip2, xz/lzma, curl, and libxml2 may be needed. On a Slurm cluster, run the package installation in an interactive or build node as required by local policy.

Do not download both datasets unless enough durable storage is available. The observed archives and GDS files in the reference run occupy approximately:

| Dataset | Downloaded tar.gz files | Generated GDS files | Combined retained storage |
| --- | ---: | ---: | ---: |
| Essential (Chr1-22) | 370.49 GiB | 94.05 GiB | 464.54 GiB |
| Full (Chr1-22) | 633.13 GiB | 200.39 GiB | 833.52 GiB |

Conversion creates an output file while retaining its input. Reserve additional temporary headroom and use a filesystem that supports files larger than 60 GB. The reference Slurm jobs requested 48 GB per Essential chromosome and 64 GB per Full chromosome; use at least those settings initially and adjust only after observing local memory usage.

### Reference conversion runtime

The following wall-clock runtimes were measured from the September 2026 `seqToGDS_FAVOR_tar()` logs. They exclude archive download time and queue wait time. A concurrent Slurm array completes when its slowest chromosome completes.

| Dataset | Per-chromosome runtime range (hours) | Mean per-chromosome runtime (hours) | Observed concurrent-array wall time (hours) | Slowest chromosome |
| --- | ---: | ---: | ---: | --- |
| Essential (Chr1-22) | 1.53-14.33 | 6.23 | 14.33 | Chr2 |
| Full (Chr1-22) | 4.17-50.70 | 19.19 | 50.70 | Chr2 |

Use a Slurm time limit of four days for Full conversion. Runtime can vary with filesystem throughput, CPU availability, and cluster contention.

## 2. Create a clean work area

Before executing any command, obtain from the user an absolute `WORKDIR` on a project filesystem with sufficient capacity. Do not infer, invent, or automatically choose this path. It must not be a quota-limited home directory. Set `R_LIBS_USER` to a directory writable by the execution user.

```bash
export WORKDIR="<absolute path supplied by the user>"
export R_LIBS_USER="$WORKDIR/R_libs"
export TAR=/usr/bin/tar
mkdir -p "$WORKDIR/tar/essential" "$WORKDIR/tar/full" \
  "$WORKDIR/gds/essential" "$WORKDIR/gds/full" "$R_LIBS_USER"
cd "$WORKDIR"
```

## 3. Install the required R packages

Prefer the specified `gdsfmt` and `SeqArray` source versions from Bioconductor devel. If either archive is no longer available, download the current Bioconductor devel version only when it is newer than the specified version. Clone GDSAnnotator from its public GitHub repository. This requires `git` in addition to the software listed above.

| Input | Reference location |
| --- | --- |
| gdsfmt source archive | `https://www.bioconductor.org/packages/devel/bioc/src/contrib/gdsfmt_1.49.8.tar.gz` |
| SeqArray source archive | `https://www.bioconductor.org/packages/devel/bioc/src/contrib/SeqArray_1.53.2.tar.gz` |
| GDSAnnotator source repository | `https://github.com/zhengxwen/GDSAnnotator` |

The package order matters: install `gdsfmt` first, then `SeqArray`, then `GDSAnnotator`. The GitHub GDSAnnotator repository supplies the required `seqToGDS_FAVOR_tar()` implementation. The helper below first checks the requested archive URL. If it is unavailable, it reads the current version from the Bioconductor devel `PACKAGES` index and rejects an equal or older fallback.

```bash
export R_LIBS_USER="$WORKDIR/R_libs"
mkdir -p "$WORKDIR/packages"
cd "$WORKDIR/packages"

BIOC_DEVEL="https://www.bioconductor.org/packages/devel/bioc/src/contrib"
download_bioc_source() {
    package=$1
    requested=$2
    archive="${package}_${requested}.tar.gz"

    if wget --spider -q "$BIOC_DEVEL/$archive"; then
        wget --continue "$BIOC_DEVEL/$archive" >&2
    else
        available=$(wget -qO- "$BIOC_DEVEL/PACKAGES" | awk -v package="$package" '
            $0 == "Package: " package { found=1; next }
            found && /^Version: / { sub(/^Version: /, ""); print; exit }
            found && /^$/ { exit }
        ')
        [[ -n "$available" ]] || { echo "No devel version found for $package" >&2; return 1; }
        Rscript --vanilla -e '
            version <- package_version(commandArgs(TRUE))
            if (version[2L] <= version[1L]) stop("Bioconductor fallback is not newer")
        ' "$requested" "$available"
        archive="${package}_${available}.tar.gz"
        wget --continue "$BIOC_DEVEL/$archive" >&2
    fi
    printf '%s\n' "$archive"
}

gdsfmt_archive=$(download_bioc_source gdsfmt 1.49.8)
seqarray_archive=$(download_bioc_source SeqArray 1.53.2)
git clone https://github.com/zhengxwen/GDSAnnotator.git
R CMD INSTALL -l "$R_LIBS_USER" "$gdsfmt_archive"
R CMD INSTALL -l "$R_LIBS_USER" "$seqarray_archive"
R CMD INSTALL -l "$R_LIBS_USER" GDSAnnotator
```

Confirm that the installed dependency versions meet the required minimums and that the converter is available before downloading hundreds of GB:

```bash
Rscript --vanilla -e 'library(GDSAnnotator); stopifnot(packageVersion("gdsfmt") >= "1.49.8", packageVersion("SeqArray") >= "1.53.2"); cat("gdsfmt ", as.character(packageVersion("gdsfmt")), "\n", sep=""); cat("SeqArray ", as.character(packageVersion("SeqArray")), "\n", sep=""); stopifnot(exists("seqToGDS_FAVOR_tar", where=asNamespace("GDSAnnotator"), inherits=FALSE))'
```

Minimum supported versions are `gdsfmt 1.49.8` and `SeqArray 1.53.2`. A higher Bioconductor devel version is acceptable only when the corresponding specified archive is unavailable.

## 5. Convert one archive to GDS

Create `convert_favor_tar.R` in `$WORKDIR`. The script accepts a dataset name (`essential` or `full`) and a chromosome. It calls `seqToGDS_FAVOR_tar()` directly with the converter defaults used by the reference run: LZMA compression, 32-bit floating-point annotation values, and 100,000 input rows per block.

```r
#!/usr/bin/env Rscript
args <- commandArgs(trailingOnly = TRUE)
if (length(args) != 2L || !args[1L] %in% c("essential", "full")) {
    stop("Usage: convert_favor_tar.R <essential|full> <chromosome>")
}

dataset <- args[1L]
chromosome <- args[2L]
workdir <- Sys.getenv("WORKDIR")
if (workdir == "") stop("Set WORKDIR before running this script.")

library(GDSAnnotator)

prefix <- if (dataset == "essential") "FAVOR.Ess" else "FAVOR.Full"
tar_file <- file.path(workdir, "tar", dataset,
    sprintf("%s.Chr%s.tar.gz", prefix, chromosome))
gds_file <- file.path(workdir, "gds", dataset,
    sprintf("favor_annot_%s_chr%s.gds", dataset, chromosome))

stopifnot(file.exists(tar_file))
seqToGDS_FAVOR_tar(tar_file, gds_file,
    compress = "LZMA", use_float32 = TRUE, block_size = 100000L)

q("no")
```

Run one small chromosome as a smoke test before submitting all chromosomes:

```bash
# Use the WORKDIR supplied by the user in Section 2.
export R_LIBS_USER="$WORKDIR/R_libs"
Rscript --vanilla "$WORKDIR/convert_favor_tar.R" essential 22
Rscript --vanilla "$WORKDIR/convert_favor_tar.R" full 22
```

To run all autosomes on one machine sequentially, substitute `essential` or `full`:

```bash
for chromosome in $(seq 1 22); do
  Rscript --vanilla "$WORKDIR/convert_favor_tar.R" essential "$chromosome"
done
```

## 6. Run all chromosomes with Slurm

To submit chromosome conversions to the cluster concurrently, save this as `submit_favor_gds.slurm`. Submit Essential and Full as separate arrays because their memory requirements differ. The `%22` limit allows up to 22 simultaneous chromosome jobs; lower this limit if the cluster allocation or filesystem cannot support that concurrency.

```bash
#!/usr/bin/env bash
#SBATCH --job-name=favor-gds
#SBATCH --array=1-22%22
#SBATCH --cpus-per-task=1
#SBATCH --time=4-00:00:00
#SBATCH --output=favor-gds-%A_%a.out

set -euo pipefail
dataset=${1:?Usage: sbatch submit_favor_gds.slurm <essential|full>}
case "$dataset" in
  essential) ;;
  full) ;;
  *) echo "dataset must be essential or full" >&2; exit 2 ;;
esac

# Use the WORKDIR supplied by the user in Section 2.
export R_LIBS_USER="$WORKDIR/R_libs"
Rscript --vanilla "$WORKDIR/convert_favor_tar.R" "$dataset" "$SLURM_ARRAY_TASK_ID"
```

Add one of these settings to the Slurm script before each submission:

```bash
#SBATCH --mem=48G   # Essential
#SBATCH --mem=64G   # Full
```

Then submit:

```bash
sbatch submit_favor_gds.slurm essential
sbatch submit_favor_gds.slurm full
```

## 7. Validate generated GDS files and record sizes

Do not regard a job as successful solely because an output file exists. This check opens each GDS, verifies the expected root format and core nodes, then writes a tab-separated manifest with source and output sizes in bytes and GiB.

```r
#!/usr/bin/env Rscript
args <- commandArgs(trailingOnly = TRUE)
if (length(args) != 1L || !args[1L] %in% c("essential", "full")) {
    stop("Usage: validate_favor_gds.R <essential|full>")
}

dataset <- args[1L]
workdir <- Sys.getenv("WORKDIR")
if (workdir == "") stop("Set WORKDIR before running this script.")

library(gdsfmt)
prefix <- if (dataset == "essential") "FAVOR.Ess" else "FAVOR.Full"
result <- lapply(1:22, function(chromosome) {
    source_file <- file.path(workdir, "tar", dataset,
        sprintf("%s.Chr%d.tar.gz", prefix, chromosome))
    gds_file <- file.path(workdir, "gds", dataset,
        sprintf("favor_annot_%s_chr%d.gds", dataset, chromosome))
    stopifnot(file.exists(source_file), file.exists(gds_file))
    gds <- openfn.gds(gds_file, readonly = TRUE)
    on.exit(closefn.gds(gds), add = TRUE)
    stopifnot(identical(get.attr.gdsn(gds$root, "FileFormat"), "SEQ_ARRAY"))
    for (node in c("variant.id", "position", "chromosome", "allele", "annotation/info")) {
        stopifnot(!is.null(index.gdsn(gds, node, silent = TRUE)))
    }
    closefn.gds(gds)
    data.frame(
        chromosome = chromosome,
        source_file = basename(source_file),
        source_bytes = file.info(source_file)$size,
        source_GiB = file.info(source_file)$size / 2^30,
        gds_file = basename(gds_file),
        gds_bytes = file.info(gds_file)$size,
        gds_GiB = file.info(gds_file)$size / 2^30
    )
})

manifest <- do.call(rbind, result)
manifest[c("source_GiB", "gds_GiB")] <- lapply(
    manifest[c("source_GiB", "gds_GiB")], round, digits = 2)
output_file <- file.path(workdir, sprintf("favor_%s_gds_manifest.tsv", dataset))
write.table(manifest, output_file, sep = "\t", row.names = FALSE, quote = FALSE)
print(manifest, row.names = FALSE)
```

Run the validation once after the corresponding Slurm array completes:

```bash
Rscript --vanilla "$WORKDIR/validate_favor_gds.R" essential
Rscript --vanilla "$WORKDIR/validate_favor_gds.R" full
```

## 9. Enhance Full GDS files with rsID

The Full GDS files have an empty `annotation/id`; the matching Essential GDS files contain rsID values. Run the following script only after both Essential and Full conversions have completed successfully. It transfers `annotation/id` from each Essential GDS to its matching Full GDS.

A complete read-only comparison of the September 2026 reference files found that, for every chromosome from 1 through 22:

- Essential and Full have the same variant count.
- Their `chromosome` and `position` vectors are in the same order.
- Their complete `chromosome + position + allele` key sets are identical in both directions, with no duplicate keys.
- Alleles within the same position are frequently ordered differently. Therefore, rsID must **not** be copied by row number or `variant.id`.

The script reads the complete `position` and `allele` vectors, maps each Full key to the matching Essential key with `match()`, and places rsID in Full order. It expects GDS files under `$WORKDIR/gds/essential` and `$WORKDIR/gds/full`, matching the output directories used in Steps 2 and 5.

Create `enhance_full_rsid.R` in `$WORKDIR`:

```r
#!/usr/bin/env Rscript

args <- commandArgs(trailingOnly = TRUE)
if (length(args) != 1L) {
    stop("Usage: enhance_full_rsid.R <chromosome>")
}

chromosome <- as.integer(args[1L])
if (is.na(chromosome) || chromosome < 1L || chromosome > 22L) {
    stop("Chromosome must be an integer from 1 to 22.")
}

workdir <- Sys.getenv("WORKDIR")
if (workdir == "") stop("Set WORKDIR before running this script.")

essential_file <- file.path(workdir, "gds", "essential",
    sprintf("favor_annot_essential_chr%d.gds", chromosome))
full_file <- file.path(workdir, "gds", "full",
    sprintf("favor_annot_full_chr%d.gds", chromosome))
stopifnot(file.exists(essential_file), file.exists(full_file))

library(gdsfmt)
library(SeqArray)

essential <- NULL
full <- NULL
on.exit({
    if (!is.null(essential)) try(seqClose(essential), silent = TRUE)
    if (!is.null(full)) try(seqClose(full), silent = TRUE)
}, add = TRUE)

essential <- seqOpen(essential_file, readonly = TRUE)
full <- seqOpen(full_file, readonly = TRUE)

essential_count <- objdesp.gdsn(index.gdsn(essential, "variant.id"))$dim
full_count <- objdesp.gdsn(index.gdsn(full, "variant.id"))$dim
if (essential_count != full_count) {
    stop(sprintf("Chr%d variant-count mismatch: Essential=%d, Full=%d",
        chromosome, essential_count, full_count))
}

essential_position <- seqGetData(essential, "position")
full_position <- seqGetData(full, "position")
essential_allele <- seqGetData(essential, "allele")
full_allele <- seqGetData(full, "allele")
essential_key <- paste(essential_position, essential_allele, sep = ":")
full_key <- paste(full_position, full_allele, sep = ":")

if (anyDuplicated(essential_key) || anyDuplicated(full_key)) {
    stop(sprintf("Chr%d contains a duplicate position/allele key", chromosome))
}

essential_index <- match(full_key, essential_key)
if (anyNA(essential_index) || anyDuplicated(essential_index)) {
    stop(sprintf("Chr%d position/allele key sets differ", chromosome))
}

essential_rsid <- seqGetData(essential, "annotation/id")
mapped_rsid <- essential_rsid[essential_index]

seqClose(essential)
essential <- NULL
seqClose(full)
full <- NULL

full <- seqOpen(full_file, readonly = FALSE)
seqAddValue(full, "annotation/id", mapped_rsid, replace = TRUE)
seqClose(full)
full <- NULL
cleanup.gds(full_file)

message(sprintf("Chr%d: annotation/id added to %s", chromosome, full_file))
```

Smoke-test chromosome 22 first, then run all autosomes sequentially:

```bash
export WORKDIR="<absolute FAVOR directory supplied by the user>"
Rscript --vanilla "$WORKDIR/enhance_full_rsid.R" 22

for chromosome in $(seq 1 22); do
  Rscript --vanilla "$WORKDIR/enhance_full_rsid.R" "$chromosome"
done
```

The script updates a Full GDS in place. Keep a backup or filesystem snapshot of `$WORKDIR/gds/full` if the pre-enhancement files must be preserved. Because it reads complete vectors and creates two composite key vectors, run one chromosome at a time on a high-memory node.

## 10. Important behavior and troubleshooting

- The output is a SeqArray-format GDS with `FileFormat = "SEQ_ARRAY"`, reference `GRCh38`, and FAVOR fields under `annotation/info`. It is not an annotated genotype GDS because FAVOR supplies annotations only.
- `seqToGDS_FAVOR_tar()` finds and orders all `.csv` members in the tar archive. Do not pass a manually extracted CSV to this workflow.
- The converter defaults to LZMA compression and 32-bit float values. Changing `compress`, `use_float32`, or `block_size` changes size, runtime, and potentially numerical storage precision; do not compare such output byte-for-byte with this manifest.
- A tar archive with a valid gzip stream but no `.csv` member will fail conversion. The archive validation command catches this before a costly job is submitted.
- If `R CMD INSTALL` fails at `SeqArray`, confirm that the custom `gdsfmt 1.49.8` was installed into the same `R_LIBS_USER` and that `Rscript -e 'library(gdsfmt)'` succeeds in the job environment.
- To preserve provenance, retain the two generated manifests, Slurm stdout/stderr, the three package sources, and the exact GDSAnnotator revision used for conversion.
